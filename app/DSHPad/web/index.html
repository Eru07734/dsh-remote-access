安装

  1. 点上面的按钮下载 APK
  2. 在通知栏或「文件管理 → 下载」里点它开始安装
  3. 若提示「禁止安装未知应用」，允许浏览器的安装权限后再试
小米 / 红米设备注意：如果安装被系统拦下，需要先打开 「设置 → 开发者选项 → USB 安装」。开启后安装会正常进行。

DSH Pad 首次连接

若 App 停在「连接设置」，说明内置 token 已过期（DSH 每次重启都会换）。 在电脑上运行 DSHPad\get-dsh-token.ps1，把输出的整条网址粘进 Token 栏即可。 服务器地址保持 <host-tailnet-ip>:3080。
